<div class="text-justify">Jiiify Presentation (JPv3) is a Java library for working with the <a 
href="https://iiif.io/api/presentation/3.0/">IIIF Presentation (v3)</a> standard. It does not contain a server, client, or <a 
href="https://en.wikipedia.org/wiki/Extract,_transform,_load">ETL</a> tool. It just provides an Java object model to assist with the 
creation and manipulation of IIIF Presentation manifests and collections.</div>

#### Getting Started

If you are completely new to Jiiify Presentation, you'll probably want to know how to obtain a copy of a pre-built Jar file (or how to 
build the project yourself). To learn more about getting your hands dirty, visit the <em>Getting Started</em> section in the left 
menu.

Alternatively, before you dive in, you may be interested in getting a big picture view of how the JPv3 library is structured, what 
sorts of extensions are supported, and how different objects are related to one another. For this sort of information, check out the 
<em>Core Concepts</em> section in the left menu.

#### Cookbook Examples

One of the best ways to familiarize yourself with JPv3 may be to look at examples that use the library. Fortunately, the IIIF 
community has a cookbook of IIIF "recipes" that people new to the specification can use to learn how to use the IIIF standard. JPv3 
uses these cookbook recipes to illustrate how one could use the JPv3 library to work with the examples from the IIIF cookbook.

There is also a live sandbox where JPv3 code snippets can be run to see, first hand, how the JPv3 library works.

Both these, the <em>Cookbook Examples</em> and the <em>Code Sandbox</em> can be found in this page's left menu.
